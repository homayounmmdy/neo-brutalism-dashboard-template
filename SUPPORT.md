# Support | Neo Brutalism UI 🎨

Thank you for using **Neo Brutalism UI**! This project aims to provide reusable Neo-Brutalist UI components and pages that developers can explore through Storybook.

If you have questions, encounter a problem, or need help using the project, here's how to get support.

## 📚 Documentation

Start by exploring the live Storybook to discover available components, examples, and UI pages.

**[Explore Neo Brutalism UI on Storybook](https://homayounmmdy.github.io/neo-brutalism-ui/)**

## 🐛 Report a Bug

If you encounter a bug or unexpected behavior:

1. Check existing GitHub issues to see whether the problem has already been reported.
2. If it hasn't, open a new issue in the repository.
3. Include steps to reproduce the problem, expected behavior, actual behavior, and screenshots when relevant.

## 💡 Request a Feature

Have an idea for a new component, an improvement, or another feature?

Open a GitHub issue describing your idea, the problem it solves, and how it could improve the library.
