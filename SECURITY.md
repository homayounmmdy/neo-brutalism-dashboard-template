# Security Policy

## Project Scope

Neo Brutalism UI is a UI component library and demonstration project focused on design, reusable components, and page layouts.

**Security is not the primary goal of this project.** Some pages, including login, authentication, and other account-related interfaces, are provided for UI demonstration purposes only.

These interfaces may not implement real authentication, authorization, secure session management, or backend security controls.

## Important Notice

- Login and registration pages do not necessarily provide real authentication.
- Forms and account-related interactions may be simulated or use client-side state.
- Client-side validation is not a substitute for server-side validation.
- UI components do not guarantee data protection or application security.
- Demo data and local storage must not be considered secure storage for sensitive information.

## Using This Project in Production

You are free to use, modify, and extend this project under the MIT License. However, **you are responsible for the security of any application you build using this code.**

Before using it in a production environment, you should:

- Implement secure authentication and authorization.
- Validate and sanitize input on the server.
- Protect sensitive data and credentials.
- Configure secure session management and cookie settings.
- Implement appropriate access controls and API security.
- Review dependencies and address applicable vulnerabilities.
- Perform security testing appropriate to your application.

Do not use demonstration login pages or simulated authentication as the sole security mechanism for a real application.

## Reporting Security Issues

If you discover a security issue in this repository, please report it through the repository's GitHub Issues or another appropriate private reporting channel if one is available.

Please avoid sharing sensitive information or exploitable details publicly before the issue has been assessed.
